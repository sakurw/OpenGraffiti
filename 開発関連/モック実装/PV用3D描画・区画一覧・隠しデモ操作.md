2026-10-29。現行画面の入口は `src/PVApp.tsx`。この文書は、従来の壁面別2Dキャンバスに代わる、今回の撮影用画面の引継ぎ資料です。

## 起動と撮影

`scripts/launchers/OpenGraffiti.bat` を実行します。通常画面は http://127.0.0.1:3100/areas/tocho/city 。サーバーは非表示で起動し、既に起動していれば再利用します。

隠し操作画面は http://127.0.0.1:3100/demo-control 。通常画面のナビゲーションには出しません。同じブラウザー・同じオリジン（ホスト名とポートを含む）の別ウィンドウで開き、この操作画面へフォーカスしてキー入力します。

| キー | 操作 |
|---|---|
| Space | 減退の再生・停止 |
| Home | 最後に保存した作品の時点へ戻す |
| ← / → | 1秒戻す・進める |

通常画面に再生バーや停止ボタンはありません。減退は15秒。Home→Spaceで先頭から再生できます（既に再生中の場合はSpaceで一度停止してから操作）。操作画面の状態表示を確認してください。撮影画面と操作画面はBroadcastChannelとlocalStorageで時計を同期します。モデル位置は変更しません。

1. 3D都市で建物をクリックするか、下部の建物選択から選びます。
2. サイドバーの北・東・南・西・屋根タブで視点を選び、「3Dで描く」を押します。
3. 描画画面は1棟だけを表示します。左ドラッグで3D表面に描画、右ドラッグで回転、ホイールで拡大します。回転ツールでは左ドラッグでも回転できます。
4. B=ブラシ、S=スプレー、E=消しゴム、V=回転、[ / ]=サイズ、Ctrl+Z=取り消し、Ctrl+Shift+Z / Ctrl+Y=やり直し。
5. 「街へ反映」で作品を保存します。編集開始時点の退色を下地に焼き込み、その上に描くため、途中の状態への上書きが可能です。
6. 建物サイドバーのギャラリーから保存した各作品を3Dで確認できます。履歴表示は減退しません。
7. 区画一覧は真上からの平行投影です。ピンクの直線をクリックすると道路沿いの水平視点に移り、左・右の建物を排他的に切り替えます。「この道を歩く」からウォークスルーへ移ります。
8. ウォークスルーは画面をクリックしてからWASD、ドラッグで見回し、Shiftで加速します。

## 正式採用モデルとの対応

正本は [正式採用方式](../設計/PLATEAU建物テクスチャ生成/正式採用方式.md)。範囲は `public/assets/tocho-twelve-blocks-20261019/scope.json` の127棟。新しい描画用GLBは `scripts/build-pv-adopted-model.mjs` で、その範囲の公式B3DMから三角形とネイティブUVを抽出しています。建物形状・都市内の座標を変形・移動しません。材質は採用済みown-onlyアトラスと、同方式の手続き生成材質です。元写真材質へのフォールバック、代替建物の形状は使いません。道路・橋も採用範囲の公式データから取得します。

出力は `public/assets/pv-adopted-20261029/city.glb` と `manifest.json`。manifestには元スコープ・GLB・元B3DMのSHA256、建物ID、パーツ、境界を記録します。出力は127棟、64,367三角形、約12MBです。建物IDはUIから除き、内部の照合にのみ使います。

描画はレイキャストのUVに透明なCanvasTextureを重ねます。ブラシはヒットした三角形のUV領域でクリップし、隣のUV領域へのはみ出しを抑えます。3Dモデルの上に描いており、従来の独立した正面図画像への描画ではありません。

正式採用方式の既知の制約（83棟のプロファイル、個別写真なしの手続き生成44棟、全面写真対応の認証未完了）は継続します。今回それを写真で復元できたとは扱いません。

## 保存と未確定事項・制約

ユーザー回答で確定したこと：建物の回転・拡大は閲覧操作であり、都市内の配置変更ではありません。減退は15秒、再生操作は隠し画面のキー入力です。

| 項目 | 現在の扱い・残る制約 |
|---|---|
| 保存先 | このPV画面の作品・履歴はブラウザーのIndexedDB。再読込後も残ります。同じオリジンの別タブで同期します。従来のサーバー側壁面作品は移行せず、元データを残しています。別ブラウザー・別PCへの共有やバックアップは未実装です。 |
| 道の定義 | 正式採用街区の直線境界を選択用の道路候補にしています。正式な道路中心線データではなく、一部は歩道側に寄る可能性があります。名称も街区と通り番号による仮名です。 |
| 道路左右の判定 | 道に沿う距離と建物中心点で分類します。交差点や巨大建物は見た目上の所属とずれる場合があり、各道路の所属を手動確定する作業は未実施です。左右の同時表示はしません。 |
| 地表・衝突 | 公式道路・橋の高さを参照し、水平のレイキャストで壁への衝突を判定します。階段・橋の上下選択などの完全な歩行ナビゲーションは未実装です。 |
| 撮影の保存 | 動画の録画・書き出しはOSや外部の撮影機能で行います。アプリ内の録画機能はありません。 |
| 同時編集 | 単独のPV撮影を想定しています。複数人の同じ建物への同時編集と競合解決は未実装です。 |

## 検証・再開手順

ローカルNodeは `.tools/node-v24.20.0-win-x64/node.exe`。以下はそのNodeまたはPATHのNodeで実行します。

```text
node scripts/build-pv-adopted-model.mjs
node scripts/runtime.mjs build
node scripts/runtime.mjs e2e --config playwright.pv.config.ts
node scripts/audit-tocho-texture-provenance-20261019.mjs --strict
node scripts/build-tocho-own-only-atlases-20261018.mjs --verify
```

PV用E2Eはポート3104で隔離起動します。127棟のID一致、シェーダーエラーなし、建物クリック・方位、3D描画の実際の色変化、取り消し・回転・保存、別タブの時計同期、15秒後の退色、途中の下地への上書き、履歴再読込、道路クリック・左右排他表示、WASD移動を確認します。旧壁面画面のE2Eは現行画面の受入テストとしては使いません。

最終実行はPV用E2E **3件合格（24.9秒）**。3D都市でページ例外・シェーダーエラーなし、地図上の道路線への実クリック、左右排他表示、WASD移動まで確認しました。390px幅の都市画面も横方向のはみ出しなしを確認しています。

テクスチャ監査は679ファイル、欠落0、ハッシュ不一致0、整合性問題0。own-onlyアトラス検証は83棟・21画像で合格しました。実画面の検証画像は `test-results/pv-*.png`、失敗時トレースは `test-results/pv/` に出ます。
