# パレット常設・空背景・PLATEAU座標の全頂点監査（2026-11-01）

この文書が現行仕様です。2026-10-31の「建物基部へ地面を合わせる」補間方式は撤回し、公式地形の座標を保持する方式へ変更しました。

追加改修：[道路面の復帰・横向き地面・退色サンプル](道路面の復帰・横向き地面・退色サンプル_20261101.md)。道路の表示と歩行高さに関する最新仕様は追加改修を参照。

## 描画画面と背景

- 32色スロット、現在のスロット番号、透過カラーをブラシ設定に常設。パレットの色を編集すると、選択中のスロットへ保存します。
- RGBAのスライダーと数値入力、HEX/RGB/HSLは「色を編集」の非モーダルポップアップに集約。現在の色を表示するプレビュースロットを1つ配置し、透明度は市松模様の上で確認できる。ポップアップはパレットを覆わず、外側クリック・Escで閉じます。
- RGBAスライダーはAdobe React Aria Components 1.22.1の `ColorSlider` / `SliderTrack` / `ColorThumb` を採用。チャンネルのグラデーション、現在色のつまみ、キー操作、フォーカス表示を提供。参照: https://react-aria.adobe.com/ColorSlider
- ポップアップにスポイトを追加。ブラウザーのEyeDropper APIで画面のRGBを取得し、現在のαを保持して選択スロットへ保存。Escのキャンセルでは変更しない。非対応ブラウザーでは無効化と説明を表示。
- 検証: TypeScript・Viteビルド成功。既存のパレット/レイヤー/描画反映、スライダー/ポップアップの2テストと、新規スポイト連携テスト1件が成功。新規テストは取得色・キャンセルをAPI差し替えで再現し、α保持・保存・プレビュー同期・トラッククリック・1280×720での配置を確認。OS上のネイティブ実採色は未確認。
- 3D都市・道路沿い・ウォークスルーに青空と雲の静的な背景を追加。描画画面は空を表示せず、従来の無地背景を使用。背景のための外部画像取得や連続アニメーションはありません。地図と作品サムネイルは従来の背景を保持します。

## 高さについて判明した問題と修正

以前の地面は道路や建物基部から推測・補間していたため、公式の地形ではありませんでした。今回、同年度の公式CityGMLのDEM（地形TIN）を取得し、元の三角形と頂点をそのまま使用しました。建物の基部へ地面を持ち上げる処理、仮設基礎の追加、勾配の平滑化は行いません。

以前の地形と公式DEMを対象街区内81,307点で比較すると、差の絶対値は平均約2.257m、最大約10.263mでした。従来の「126棟の底面に接地した」という検査は、PLATEAUとの座標一致を証明するものではありません。

## 全頂点の照合結果

| 対象 | 検証 | 結果 |
|---|---|---|
| 採用建物127棟 | 公式B3DMから別ディレクトリへ再生成し、採用GLBと比較 | バイト単位で同一 |
| 建物76,416頂点 | 元CityGMLとの座標照合 | 未対応0、最大差0.036447m（配布3D Tilesの量子化を含む） |
| DEM65,796頂点 | 元GMLの座標を同じフレームへ変換し、描画GLBと全数照合 | 全頂点がFloat32丸め結果と一致、最大丸め差0.000030517m |

頂点と三角形の接続を全数保持するため、選択した地形の各三角形内部でも元データの面を保持します。街区全体の無限個の位置を個別に測量したという意味ではありません。地面の表示は同じDEM三角形を参照します。歩行時は元の道路面がある位置ではその高さを優先し、それ以外でDEMを参照します。

## 一致の範囲と残る制限

- **建物と地面の座標を元データへ一致させることと、全建物の底面を地面へ接触させることは異なります。** 元データにも建物底面がDEMより低い・高い箇所があります。底面6,002点の高低差は約-9.697〜+14.387mでした。地下・基壇・高架等の種別や原因を全件認定したわけではありません。今回は高さを改変せず、その相対関係を保持しています。
- 建物は採用済みの公式LOD形状を使用します。LODの異なる別モデルや現在の実景との完全一致は、今回の照合対象ではありません。
- 地図の選択範囲とDEM上の補助着色は公式184道路ポリゴンです。3Dでは採用モデル内の元の道路・橋を表示し、道路面がDEMに埋まる部分だけDEMの描画を除外します。DEMや道路の頂点を持ち上げたり平滑化したりしていません。元の多層道路の全構造や現実の擁壁まで復元したという意味ではありません。
- 地形の選択範囲外は今回の全頂点監査の対象外です。選択した地形を街区に十分な余裕を持って表示しています。

原本がない場合：

```powershell
node scripts/plateau-download.mjs plateau-13104-shinjuku-ku-2025 @data/texture-city/pv-official-dem-selection-20261101.json --extract
```

地形の再生成と検査：

```powershell
node scripts/build-pv-terrain.mjs
node scripts/build-pv-roads.mjs
node scripts/audit-pv-surface.mjs
```

`build-pv-terrain.mjs` は公式DEM生成処理を呼び出します。以前の補間地形へ戻す入口にはしません。建物原本の再照合は `PV_MODEL_OUT` を別の出力先に設定して `build-pv-adopted-model.mjs` を実行し、`audit-pv-native-coordinates.mjs` を使用します。採用済み `city.glb` を上書きする必要はありません。
