# PV画面改修・レイヤー描画・道路座標修正

2026-10-31。今回のユーザー指示に対する現行実装と検証記録です。2026-10-29版の操作仕様より本書を優先します。

## 都市・サイドバー

- 建物のクリック・選択解除と壁面タブではカメラ位置・注視点を変更しません。タブはサイドバーの面別画像を切り替えます。選択時に全シーンを組み直す処理を除き、選択枠だけを更新します。
- `pv-bottom-bar`を除去。主ナビはデスクトップでは画面中央へ配置し、小画面ではロゴ下の中央へ移します。
- ナビの参照：[Material Designのタブ](https://m2.material.io/components/tabs/web)、[Figmaのナビゲーションとキャンバスの構成](https://help.figma.com/hc/en-us/articles/360039831974-Explore-the-navigation-bar-and-left-sidebar)。アプリ間移動を上部にまとめ、作業ツールを左右のパネルに置く方針を参照しています。中央配置はこのアプリの3つの行き先とユーザー希望に合わせた判断です。
- 以前のサイドバーのうち、画像、現在の版、作品名、作者、退色進行、作品数、描画・履歴への操作を復元しました。指示された寸法・出典・ID・補足説明・非表示アイコンは戻しません。元の建物でも面別の実モデル画像を表示します。
- 都市は左ドラッグで移動、右ドラッグで回転、ホイールで拡大。移動2.5倍、回転1.8倍、ズーム2.7倍を設定。操作方法は項目ごとに改行し、開閉時も横幅を固定します。

## 3D描画

描画画面は1棟、モデルの都市内配置を変更しません。左ドラッグで描画、右ドラッグで回転、ホイールで拡大。独立した回転ツールと「建物を回して描く」セクションは削除しました。

| 項目 | 現行仕様 |
|---|---|
| ツール | ブラシ B、スプレー S、消しゴム E、範囲内塗りつぶし F。取り消しCtrl+Z、やり直しCtrl+Y / Ctrl+Shift+Z。キーを各項目の下へ薄く表示します。 |
| 種類 | ブラシ・消しゴムは丸筆、ソフト、平筆、点描。スプレーは細粒、粗粒、ミスト。 |
| サイズ・粒子 | サイズ、密度、粒度。粒度を大きくし密度を下げると粗い点描になります。ポインターは設定サイズの円です。 |
| カラー | 32スロット。選択中スロットに色変更を保存し、localStorageへ永続化。RGBAの数値、HEX（#RRGGBBAAを含む）、rgb()/rgba()、hsl()/hsla()等のCSS色入力に対応。独立した「不透明度」設定は削除。αは0〜1。 |
| 透過カラー | 選択レイヤーに抜きマスクを描き、それより下の描画と引継ぎ下地を抜いて、元の建物材質を表示します。上のレイヤーの描画は残ります。消しゴムは選択レイヤーの描画・抜きマスクだけを消します。 |
| レイヤー | 最大10。追加、複製、名前変更、表示切替、削除、上下移動。レイヤー0の建物は固定。保存する版には合成画像と編集レイヤーの色情報・抜きマスクを記録します。新しい版への描き始めは、従来どおりその時点の退色を固定下地として引き継ぎます。 |
| 塗りつぶし | 選択レイヤーのクリックした色からつながる範囲を、クリック面と共面のUV領域内で塗ります。色の許容差を設定可能です。 |

### 負荷の見直し

`src/pv-paint.ts`へ画素処理を分離しました。ストロークごとの同期PNG生成・復号を除去し、Undoはコピーオンライト方式で変更するパーツだけをメモリー上に複製します。8段階のUndoを保持します。PNGへの変換は公開・保存時に行います。

レイキャストをMeshBVHで高速化し、ポインターの入力をrequestAnimationFrameにまとめ、サイズに応じた間隔でサンプリングします。CanvasTextureの更新は変更パーツについて1フレーム1回。ミップマップと異方性フィルタは維持します。退色表示の参照も建物IDのMapへ変更しました。GPUへの全体テクスチャ転送と、大きな範囲の塗りつぶし・保存の一時的な処理時間は残ります。PCごとの体感速度を保証するベンチマーク値は付けていません。

## 道路・2D表示・ウォークスルー

前回の街区データの`polygonENU`は、生成時点ですでにX=東、Z=南でした。前回のPV実装がZを再反転していたため、選択道路と地面のクリップが南北にずれていました。`scripts/build-pv-adopted-model.mjs`の外周と道路候補を修正しました。建物の形状と座標は変更していません。地面側の選択が修正された結果、出力全体は64,612三角形です。

`scripts/build-pv-roads.mjs`は既存の公式CityGML LOD1道路ポリゴンから直線を抽出し、測地系→ECEF→表示座標へ変換します。街区境界で代用する処理は廃止しました。現行は9区間で、公式道路メッシュ上の高さ97点を保持します。道路ID・原本のSHA256・直線近似の幅とずれを`public/assets/pv-adopted-20261029/roads.json`に記録します。選択線は道路ポリゴンの主軸であり、測量済みの道路中心線という意味ではありません。

道路選択後は正投影の水平視点に固定します。選択側の全建物の境界から表示範囲を計算し、長い道路でも全体を収めます。道路の反対側と背景道路は表示しません。マウスの移動・回転・ズーム・建物選択は無効にし、左右切替、地図へ戻る操作、ウォークスルーへの入口を残します。対象範囲外の側は空である旨を表示します。PLATEAU-2Dのような街並みの横方向の見せ方を参考としていますが、同サービスと同じ生成アルゴリズムや出力品質を保証するものではありません。

ウォークスルーは通常12m/s、Shiftで40m/s、道路面の高さ+3.4mを目線とします。右・左ドラッグで見回し、マウスの横方向の符号を以前と逆にしました。実際の道路三角形を参照し、穴では同じ道路の高さサンプルを利用します。固定高さ85mへのフォールバックは使いません。OrbitControlsの都市用角度制限が歩行カメラを上へずらす不具合も修正しました。クリックで建物を選ぶとサイドバーを開き、現在の位置を保持します。

## ギャラリーの実演

http://127.0.0.1:3100/demo-gallery を開くと、東京都庁第一本庁舎に3つのテスト作品を追加して履歴を開きます。`pv-gallery-demo-*`の固定IDで再実行時はテスト版だけを更新し、既存の別IDの作品を削除しません。作者名は「PVテストデータ」。見やすいように減退時計を停止します。通常画面にデモボタンは追加していません。隠し操作画面からも同じデータを追加できます。

元の建物→PINK FLOW→BLUE LINE→GOLD RINGSの切替を、実ブラウザーで確認して録画しました。録画は`test-results/pv-gallery-demonstration.webm`、静止画は`test-results/pv-gallery-demonstration.png`です。テストデータも通常の作品と同じIndexedDB保存・読み込み・材質表示を使います。

## 検証

```text
node scripts/build-pv-adopted-model.mjs
node scripts/build-pv-roads.mjs
node scripts/runtime.mjs build
node scripts/runtime.mjs e2e --config playwright.pv.config.ts
```

現行の受入テストは`tests/pv/revision.spec.ts`。前回の`workflow.spec.ts`は旧操作の記録として残し、今回の設定では実行しません。

- 都市のクリック・壁面タブでカメラ位置と注視点が不変。元建物の画像と復元した情報を表示。操作方法の開閉で幅が不変。
- 32色スロット、RGBA/色コード、2レイヤー、透過カラーの描画ピクセルが元の建物の画素と一致、Undo/Redo、保存したレイヤー数、保存後のタブ切替。
- 粗いスプレーの密度・粒度、範囲内塗りつぶし、右ドラッグ回転。
- 実際の地図線へのクリック、正投影、左右の排他的表示、道路沿いでマウス操作が無効。
- 道路面+3.4m、歩行距離、見回しの左右反転、実クリックによる建物選択と位置維持。
- テスト作品3版の読み込み・切替・再読込後の永続化。

最終結果：**6件合格（32.4秒）**。作品のブラウザー内保存、複数人の競合解決未実装、公式建物テクスチャの既知の写真根拠の制約は従来どおりです。
