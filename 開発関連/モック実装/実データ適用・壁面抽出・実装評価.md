# 実データ適用・壁面抽出・実装評価（v1時点の記録）

> この文書はv1の検証記録です。現行v2ではLOD2描画・任意壁選択・道路沿い表示へ拡張しています。[最新の対応内容](LOD2拡張・道路沿いビュー・テクスチャ調査.md) を参照してください。

実施日: 2026-09-08 / datasetVersion: `plateau-2025-v1`

## 結論

操作評価用モックは、実データを用いた壁選択→固定下地→描画→3D確認→公開→一本の履歴→退色→再上書きまで実装しました。白い画像への置換ではなく、選択した実壁の元テクスチャを0番目の絵としています。編集中は取得時点の退色状態を固定します。

東京タワー北側・神谷町のLOD3建物から12壁面を採用。都庁周辺のLOD3建物は調査対象データでは確認できず、この要求は未達です。都庁はLOD2の鑑賞専用として適用し、描画対象へ混ぜていません。モックの完成は本実装・BV受け入れの完了を意味しません。

## 公式データの調査と適用

| データ・対象メッシュ | 検査した建物 | 適用 |
|---|---|---|
| 港区2025 / 53393599 | 1,258棟: LOD3 11棟、LOD2 1,247棟 | 116棟を表示。LOD3 11棟を含む。12壁を描画対象に採用 |
| 新宿区2025 / 53394525 | 1,600棟: LOD2 987棟、LOD1 613棟、LOD3/4なし | 都庁付近56棟を参考表示 |
| 新宿区2023 / 53394525 | LOD3/4建物なし | 比較調査のみ。表示には不使用 |
| 東京23区2023 LOD4専用データ | 公式説明の対象はポートシティ竹芝1棟 | 都庁代替としては不採用 |

東京タワー本体はLOD2です。描画地区は約0.9km北の神谷町とし、画面に地区名と精度を明記しています。「周辺」の採用範囲はレビュー可能な仮決定です。道路は両地区ともLOD3を適用していますが、建物のLOD判定とは別です。

出典: [港区2025](https://www.geospatial.jp/ckan/dataset/plateau-13103-minato-ku-2025)、[新宿区2025](https://www.geospatial.jp/ckan/dataset/plateau-13104-shinjuku-ku-2025)、[新宿区2023](https://www.geospatial.jp/ckan/dataset/plateau-13104-shinjuku-ku-2023)、[LOD4専用](https://www.geospatial.jp/ckan/dataset/plateau-tokyo23ku-2023-lod4)。

## 抽出・変換

1. CKANから公式ZIPのURLを取得。ZIP中央ディレクトリと必要エントリのみRange取得し、巨大ZIP全体の取得を回避。
2. CityGMLの建物・WallSurface・Polygon・ring IDとAppearanceの対応を保持。原本とSHA-256はローカルに保存。
3. JGD2011から平面直角座標系IX系へ変換し、地区原点を用いたメートル単位のローカル座標へ変換。
4. 同一WallSurfaceの同一平面ポリゴンをまとめ、開口・穴を保持して三角形化。平面誤差・傾斜・面積・寸法・縦横比・Appearance・前方空間で候補を限定。
5. 幅4m以上、高さ2.5m以上、面積12㎡以上、平面RMS 2cm以下、最大誤差5cm以下などで選別。外接矩形の充填率80%以上を保守的な条件に使用。14候補から12面を採用。
6. 元テクスチャをUVに沿って基底画像へ焼き込み。長辺2048px、短辺512px以上、実壁の縦横比を保持。壁外・開口は透明黒へ正規化。
7. 壁オーバーレイは法線方向2mmに配置し、GLBにwallIdと原本IDを格納。GLBはmeshopt圧縮。基底PNG・マスク・壁定義・カタログと整合を検証。

公式原画像は港区281枚・新宿区147枚を取得しました。低解像度・単色に近い元画像もそのまま使用しています。背景のテクスチャ非対応面と道路は中立色表示で、元の写真を創作・高精細化していません。

出力: `public/assets/datasets/plateau-2025-v1/`。GLBは東京タワー地区10,510,644bytes、都庁地区7,895,660bytes。マニフェスト対象44ファイル。通常利用は再ダウンロード不要です。

## 評価

| 項目 | 評価 | 根拠・制約 |
|---|---|---|
| 実LOD3壁への描画 | モック評価可能 | 12面の原本ID・UV・マスクを追跡可能 |
| 0番目・退色下地・上書き | 動作確認済み | 初期は全壁0番目、公開は次版追加、退色終点は元壁に画素一致 |
| 3D鑑賞・区画一括 | 動作確認済み | 2地区切替、12面一括、履歴日時指定。区画はカード配置の仮実装 |
| 壁の視認性 | 補助付きで評価可能 | 柱・庇等の遮蔽があるため周辺透過を切替可能。通常遮蔽も確認すること |
| 都庁LOD3建物 | 未達・データ制約 | 調査した公式対象メッシュに存在しない |
| 精度の正式受け入れ | 一部完了 | CPU側UV往復は検証。GPU画像MAE・街路視認性等のBV全項目は未完了 |
| 本番品質 | 未完了 | JSON保存、簡易認証、poll、性能・アクセシビリティ等は本実装前に対応 |

優先順位は、まずこのモックで地区・壁・画面フローを評価し、その後に区画展開方式、BVの正式検証、SQLite/認証/SSE、最大負荷試験へ進むことです。現時点で本番公開に適した完成品とは評価しません。

## 再生成

実行環境はローカルNode24（`.tools/node-v24.20.0-win-x64/node.exe`）を使用します。以下の `node` をそのパスに置き換えて実行可能です。

```powershell
node scripts/plateau-download.mjs plateau-13103-minato-ku-2025 53393599_bldg --extract
node scripts/plateau-download.mjs plateau-13104-shinjuku-ku-2025 53394525_bldg --extract
node scripts/plateau-download.mjs plateau-13103-minato-ku-2025 53393599_tran --extract
node scripts/plateau-download.mjs plateau-13104-shinjuku-ku-2025 53394525_tran --extract
node scripts/plateau-inspect.mjs plateau-13103-minato-ku-2025 53393599
node scripts/plateau-inspect.mjs plateau-13104-shinjuku-ku-2025 53394525
node scripts/plateau-plan.mjs
node scripts/plateau-download.mjs plateau-13103-minato-ku-2025 '@data/plateau/plateau-13103-minato-ku-2025/53393599-texture-paths.json' --extract
node scripts/plateau-download.mjs plateau-13104-shinjuku-ku-2025 '@data/plateau/plateau-13104-shinjuku-ku-2025/53394525-texture-paths.json' --extract
node scripts/plateau-build.mjs
npm run verify:plateau
npm run test:plateau
```

PowerShellで `@data/...` の解釈に問題がある場合は引数を引用符で囲みます。原本・検査結果は `data/plateau/<dataset>/`、取得元と原本SHAは同梱の `source-manifest.json` に保存。ダウンローダーはサイズ・CRC32も検査します。

この版の納品後に壁の選定・基底画像を変更する場合はdatasetVersionも更新し、既存作品と異なる基底を同じID領域へ上書きしないでください。旧生成モックの実行データは保持しています。今回の途中生成アセット36ファイルは `data/plateau/superseded-wall-assets-20260908/` に退避しており、復元可能です。
