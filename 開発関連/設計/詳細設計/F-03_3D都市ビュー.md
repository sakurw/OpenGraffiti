# F-03 3D都市ビュー 詳細設計

作成日: 2026-08-22  
ステータス: 詳細設計決定版（実データ・性能検証前）

> 実装値は[設計決定記録](設計決定記録.md)を正とする。本文中の`UD-xxx`参照は未決を意味しない。

## 1. 目的

PLATEAU実データ由来の対象エリアを3D表示し、描画対象壁面、各壁面の現在作品および現在デモ時刻における退色状態を実際の壁面位置で閲覧できるようにします。壁面選択から詳細、描画、履歴、区画一括ビューへ遷移する起点です。

## 2. 対応要件

- FR-001～008、FR-109、FR-112
- NFR-001、NFR-002、NFR-006、NFR-008、NFR-017、NFR-019
- AC-001、AC-002、AC-006、AC-009、AC-012、AC-022、AC-027

## 3. 入力

| 入力 | 取得元 | 用途 |
|---|---|---|
| Area・GLB | F-02静的成果物 | 都市モデル表示 |
| Wall・WallCanvas | F-02静的成果物 | 描画壁面識別、オーバーレイ参照、UV |
| 現在版マップ | F-01 bootstrap | 正式Artwork、revisionNo、退色入力 |
| デモ時刻 | F-11共通状態 | 現在の退色進行度 |
| 退色画像 | F-10 | 作品オーバーレイテクスチャ |
| 一時プレビュー | F-06 | 本人クライアントだけの一時テクスチャ |

## 4. 画面要素

| 要素 | 内容 | 状態 |
|---|---|---|
| 3Dキャンバス | 対象エリア、元建物、作品オーバーレイ | 読込中、表示、WebGLエラー |
| 描画壁面表示 | 通常面と区別可能な強調・ラベル | 通常、hover、選択、描画不可、読込失敗 |
| 壁面詳細パネル | 壁面名、現在版、退色段階、導線 | F-04へ連携 |
| モード切替 | 3D都市／区画一括 | F-09へ連携 |
| デモ操作パネル | 時刻、再生・停止、リセット | F-11へ連携 |
| 共通エラー | 個別画像失敗、API失敗、テクスチャ再読込 | F-01共通表示 |

選択壁はシアン2pxアウトライン、ピンアイコン、壁面名で示します。MapControlsは左pan、右rotate、wheel zoom、移動5px以下の左clickをRaycaster選択とします。

## 5. シーングラフの論理構造

```text
Scene
├─ EnvironmentRoot
│  └─ AreaGLB                     元モデル・元テクスチャ
├─ ArtworkOverlayRoot
│  ├─ Overlay[wallId=A]           現在作品または一時プレビュー
│  └─ Overlay[wallId=B]
├─ InteractionRoot
│  └─ PickingProxy[wallId=*]      壁面選択用
└─ CameraAndLights
```

- 元GLBを作品画像で書き換えません。
- 作品オーバーレイは`wallId`から一意に取得します。
- 選択用オブジェクトと表示用オーバーレイは分離してよいものとします。
- 基底画像は元外観と一致するため、0番目と`p = 1`でもF-10の出力画像をオーバーレイとして表示できます。
- unlit検証モードは受け入れ試験用で、通常表示はGLBの元PBR外観を使用します。

## 6. 初期化処理

1. F-01から検証済みArea、Wall、WallCanvas、現在版マップを受け取ります。
2. WebGL利用可否を確認します。
3. GLBを読み込み、対象ノード・プリミティブ参照を解決します。
4. 描画対象壁面ごとにオーバーレイと選択判定対象を登録します。
5. 現在Artwork画像、基底画像、マスクを必要数取得します。
6. F-10へ現在Artwork、基底、マスク、現在デモ時刻、rendererVersionを渡します。
7. 生成結果を各オーバーレイへ設定します。
8. 初期カメラを設定し、操作受付を開始します。
9. 画像読込が失敗した壁面は個別エラー状態とし、他の壁面の操作を許可します。

GLBはMeshoptだけを適用し、テクスチャは不可逆再圧縮しません。取得は同時6本です。

## 7. 描画ループ

描画ループでは、カメラ・入力・必要な退色更新・レンダリングを行います。退色PNGを毎フレーム再生成してはいけません。

1. F-11から算出したデモ時刻を参照します。
2. F-10が定義するキャッシュ単位または更新条件を満たした場合だけ退色画像を更新します。
3. 可視範囲外または画面上で極小のオーバーレイは、要件を損なわない範囲で更新優先度を下げられます。
4. 同じ入力のテクスチャ生成要求を重複させません。
5. 使用されなくなった一時テクスチャ、Object URL、GPUリソースを解放します。

退色はサーバーの`pPermille`単位PNGを取得し、SSE通知、5秒同期、タブ復帰時再同期を行います。

## 8. 壁面選択

1. ポインター入力を3Dキャンバス座標へ変換します。
2. 描画対象の選択判定オブジェクトだけを候補にします。
3. 最前面の有効な`wallId`を選択します。
4. 選択壁面を強調し、F-04の壁面詳細を開きます。
5. 静的設定不備または現在版不備がある壁面は詳細表示だけを許可できても、「描く」を表示しません。
6. 同じclick rayに複数壁が当たる場合は最前面を選び、同位置の候補数と次候補ボタンを詳細パネルへ表示します。

## 9. 現在作品の反映

### 9.1 Bootstrap時

各`wallId`について、`WallState.currentRevisionId`と応答内のWallRevision、Artworkの対応を確認し、現在作品だけを表示します。祖先Artworkを取得・合成しません。

### 9.2 公開成功時

1. F-07から新Artwork、新WallRevision、正式画像URLを受け取ります。
2. 対象`wallId`の現在版マップを置き換えます。
3. F-06の一時テクスチャを正式画像へ差し替えます。
4. 対象壁面のテクスチャキャッシュだけを更新します。
5. GLB、他壁面、カメラ状態を再初期化しません。

### 9.3 正式画像反映失敗

- 公開済みのDB状態を巻き戻しません。
- 「公開済みだが表示更新に失敗」と示します。
- 正式画像URLを再取得し、対象オーバーレイだけ再設定します。

## 10. 一時3Dプレビュー

- F-06が生成した一時PNGを、対象壁面に限り正式画像より優先表示します。
- 一時表示には未公開ラベルを付けます。
- 他クライアント、履歴、区画一括の正式状態へ反映しません。
- 編集へ戻る、キャンセル、公開成功時に一時リソースを解放します。
- プレビュー姿勢へ300msのease-outで移動し、利用者入力があれば即中断します。

## 11. テクスチャキャッシュキー

論理キーには少なくとも次を含めます。

```text
wallId
artworkImageHash
wallBaseImageHash
rendererVersion
fadeProgressNormalized
previewToken（未公開時だけ）
```

`fadeProgressNormalized`はAPIの`pPermille / 1000`を表示専用に変換した値で、hashやcache keyには使いません。

## 12. エラー処理

| 事象 | 表示・処理 |
|---|---|
| WebGL非対応・コンテキスト喪失 | 3D機能を停止し、再初期化または代替資料を案内 |
| GLB読込失敗 | 都市表示を開始せず再試行 |
| オーバーレイ参照欠損 | 該当壁面を描画不可にし設定不備を表示 |
| 現在Artwork画像失敗 | 該当壁面にエラー状態、画像だけ再試行 |
| 退色生成失敗 | 不一致画像へ代替せず、該当壁面を描画開始不可にする |
| 一時PNG適用失敗 | 編集を保持し、プレビュー不成立としてF-05へ戻れるようにする |

## 13. 性能

- 初回アクセスから操作可能な都市ビューまで8秒以内を目標とします。
- 壁面選択から詳細表示まで1秒以内を目標とします。
- 公開後は対象テクスチャだけ更新します。
- 作品画像と基底画像はハッシュ付きURLでキャッシュします。
- GPUメモリ、テクスチャ枚数、ドローコールを基準端末で記録します。
- Meshopt、テクスチャ上限4096、対象範囲縮小を使用し、RTX 4080 SUPERとIntel UHD 770で計測します。

## 14. ログ

| イベント | 項目 |
|---|---|
| GLB読込 | areaId、データ版、バイト数、所要時間、結果 |
| 壁面選択 | wallId、選択判定結果、詳細表示所要時間 |
| テクスチャ生成・適用失敗 | wallId、artworkId、rendererVersion、requestId |
| WebGL障害 | ブラウザ、GPU情報、コンテキスト状態 |

個人を追跡する閲覧ログや注目度データは収集しません。

## 15. テスト観点

- PLATEAU実データと描画対象壁面が表示される。
- 0番目、ユーザー現在作品、退色完了が選択した壁本来の外観と整合する。
- 非対称画像が正しい向き・比率・境界で表示される。
- 壁面を選択し1秒以内に詳細を表示できる。
- 3D都市とF-09で同じ時刻・同じ現在版・同じ退色結果になる。
- プレビューと公開後の向き、比率、描画範囲が一致する。
- 公開成功後にGLB全体を再読込しない。
- 1壁面の画像失敗が他壁面の閲覧を妨げない。
- 色以外でも描画可否・エラー・選択状態を判別できる。
