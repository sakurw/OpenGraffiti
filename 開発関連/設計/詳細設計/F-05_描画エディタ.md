# F-05 描画エディタ 詳細設計

作成日: 2026-08-22  
ステータス: 詳細設計ドラフト（未確定事項あり）

## 1. 目的

F-04で固定した現在作品の退色状態を編集不能な下地とし、その上へストリートアート用の編集レイヤーを重ねます。壁面外を描画せず、公開前の一時統合PNGを生成できる状態までを担当します。

## 2. 対応要件

- FR-201～224
- NFR-004、NFR-005、NFR-008
- AC-003～005、AC-021～023、AC-026、AC-028

## 3. 入力・出力

### 3.1 入力

| 入力 | 内容 |
|---|---|
| 編集コンテキスト | wallId、版、sourceAsOf、全source情報、データ版 |
| キャンバス | width、height、縦横比、マスク |
| 固定下地 | 退色反映済みRGBA画像、画像ハッシュ |
| UI初期値 | 選択ツール、色、サイズ等。具体値はUD-018 |

### 3.2 出力

| 出力 | 用途 |
|---|---|
| 編集レイヤー状態 | タブ内編集の継続 |
| dirty・描画有無 | 離脱警告、公開可否 |
| 一時統合RGBA | PNG生成前の画素データ |
| 一時統合PNG | F-06の3Dプレビューと公開候補 |
| PNG属性 | 寸法、容量、画像ハッシュ |

編集レイヤー自体をサーバーへ保存しません。

## 4. 論理レイヤー構造

```text
CanvasDocument
├─ FixedBaseLayer                編集不可・常時表示・レイヤー数外
└─ EditLayers[0..10]             初期枚数・最低保持枚数はUD-034
   ├─ layerId
   ├─ name                       命名規則はUD-034
   ├─ visible
   ├─ pixelBuffer / drawSurface  実装方式はUD-005
   └─ hasDrawing
```

通常合成だけを使用し、特殊合成モードは提供しません。編集レイヤーの初期枚数、複製、命名、並べ替え等のUndo対象範囲はUD-034です。

## 5. エディタ状態

| 状態 | 説明 | 許可操作 |
|---|---|---|
| `INITIALIZING` | 固定下地、マスク、描画面を準備 | キャンセル |
| `EDITING_CLEAN` | 編集レイヤーに描画なし | 描画、レイヤー操作、戻る |
| `EDITING_DIRTY` | 1画素以上の描画操作あり | 描画、レイヤー操作、Undo/Redo、プレビュー |
| `COMPOSITING` | 一時画像を生成中 | 完了待ち、必要に応じキャンセル |
| `PREVIEW_READY` | 一時PNG生成済み | F-06へ遷移、編集へ戻る |
| `ERROR` | 初期化・合成失敗 | 再試行、編集保持、キャンセル |

設定変更だけで`dirty`とするかはUD-034で決定します。公開可否は少なくとも可視編集レイヤーに描画内容があることを条件にします。

## 6. キャンバス初期化

1. F-04のコンテキストが対象`wallId`・データ版と一致することを確認します。
2. 固定下地、マスク、キャンバス寸法が一致することを確認します。
3. 固定下地画像のハッシュを確認します。
4. 固定下地を編集APIと分離した描画面へ配置します。
5. マスクを描画入力と最終合成の両方に設定します。
6. UD-034で決定した初期編集レイヤー構成を作成します。
7. 必須ツールのUIを初期化します。
8. Undo・Redoスタックを空にします。

いずれかの検証に失敗した場合、エディタを空白や白背景で開始しません。

## 7. 描画ツール

### 7.1 共通入力

各描画ツールはポインター座標列、色、サイズ、不透明度およびツール固有パラメータを受け取ります。マウス・ペン圧、補間、サンプリング間隔はUD-018です。

### 7.2 ツール別責務

| ツール | 確定する動作 | 未確定パラメータ |
|---|---|---|
| ブラシ | 連続線を選択編集レイヤーへ描く | 形状、補間、サイズ・硬さ範囲 |
| マーカー | ブラシと区別できる一定の描画表現を持つ | 形状、不透明度既定値、重ね塗り方式 |
| スプレー | ポインター周囲へ粒子を描く | 粒径、分布、密度範囲、乱数シード |
| 消しゴム | 選択中編集レイヤーだけを透明化し固定下地を露出 | サイズ、硬さ |
| 色 | RGB系の描画色を指定 | UI、許可形式、履歴 |
| サイズ | ツールの描画径を変更 | 最小、最大、刻み |
| 不透明度 | ブラシ、マーカー、スプレーへ適用 | 最小、最大、刻み |
| 硬さ | 必須調整項目 | 連続値またはプリセット |
| 粒子密度 | スプレーの密度を調整 | 連続値またはプリセット |

にじみ、ドリップ、ステンシル、特殊合成モード、画像取込は実装しません。

## 8. マスク適用

入力時と出力時の二段階でマスクを適用します。

1. 入力座標がマスク外の場合、新しい描画画素を作りません。
2. ストロークが境界をまたぐ場合、マスク内だけを更新します。
3. 編集中の各レイヤーはマスク外を透明に維持します。
4. 最終合成時に再度マスクを適用し、固定下地を含めてマスク内を不透明、外側を透明にします。

マスク境界のアンチエイリアスとアルファ閾値はUD-051で確定します。

## 9. 編集レイヤー操作

| 操作 | 固定下地 | 編集レイヤー |
|---|---|---|
| 追加 | 対象外 | 最大10枚まで |
| 削除 | 禁止 | 選択レイヤーを削除可 |
| 並べ替え | 禁止 | 許可 |
| 表示切替 | 禁止 | 許可 |
| 描画・消去 | 禁止 | 選択レイヤーだけ |
| Undo/Redo | 対象外 | 操作単位で各5回 |

10枚到達時は追加を無効化し、上限を文言で示します。最後の編集レイヤーを削除可能とするか、常に1枚残すかはUD-034です。

## 10. Undo・Redo

- 最大5操作をUndoスタックへ保持します。
- Undoした操作を最大5操作までRedoできます。
- Undo後の新しい操作でRedoスタックを破棄します。
- 固定下地の状態は履歴へ含めません。
- 1ストロークを少なくとも1操作単位として扱います。
- レイヤー追加・削除・並べ替え・表示切替・設定変更を操作単位へ含める範囲はUD-034です。
- 大きな画素スナップショットだけを無制限保持しない実装にしますが、差分・コマンド等の方式はUD-005に依存します。

## 11. 一時統合PNG

1. 固定下地を最下層に描画します。
2. 可視な編集レイヤーを下から順に通常合成します。
3. 壁面マスクを適用します。
4. マスク内のアルファが完全不透明、外側が完全透明であることを検証します。
5. 規定寸法でPNGへエンコードします。
6. 容量が10MB以下であることを確認します。
7. 規定方式で画像ハッシュを計算します。
8. F-06へ一時PNGと元編集コンテキストを渡します。

10MBを超えた場合に再エンコード、編集修正、壁面対象外のどれを採るかはUD-035です。勝手に解像度や画質を変更しません。

## 12. 未保存・失敗時の保持

- dirty状態で戻る、他画面へ移動、ブラウザ遷移を行うときは破棄確認を表示します。
- プレビュー生成失敗、公開失敗、競合では編集レイヤーとUndo/Redoをメモリに保持します。
- タブを閉じた後の復元は保証しません。
- 固定下地差し替えを伴う競合復帰はF-07が制御し、利用者確認なしに適用しません。

## 13. 性能

- 通常ブラシ操作は30fps以上を維持します。
- 入力点欠落で線が途切れないよう、描画フレームと入力イベントのバッファを分離できます。
- 実装ライブラリ、Worker、OffscreenCanvas、入力補間の使用はUD-005、UD-018、UD-030で決定します。
- 性能計測ではブラシ、マーカー、スプレー、消しゴム、10レイヤー、Undo/Redoを個別に測定します。

## 14. エラー・ログ

| 事象 | 処理 |
|---|---|
| 固定下地・マスク不整合 | 初期化中止、F-04へ戻る |
| レイヤー上限 | 追加を拒否、編集継続 |
| 編集内容なし | プレビューまたは公開導線を無効化 |
| PNG生成失敗 | 編集を保持して再試行 |
| PNG容量超過 | UD-035の決定方式で案内。自動公開しない |
| メモリ不足 | 編集保持可否を明示し、追加操作を停止 |

ログにはツール種別、レイヤー数、キャンバス寸法、合成時間、PNG容量、エラーを記録できますが、画像内容や全座標列を記録しません。

## 15. テスト観点

- 必須4ツールと色、サイズ、不透明度、硬さ、密度を操作できる。
- 最大10編集レイヤーと固定下地を分離できる。
- 消しゴム、削除、Undo/Redoで固定下地が変わらない。
- Undo/Redo各5回、新規操作時Redo破棄が成立する。
- マスク外へ描画できず、出力も透明になる。
- 可視編集レイヤーに描画がないと公開候補を作れない。
- 統合PNGだけで同じ見た目になり、祖先画像を必要としない。
- 公開失敗後もタブ内で編集を継続できる。
- 基準端末で30fps以上、線切れなしを確認する。
