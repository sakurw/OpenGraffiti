## 正式採用した建物テクスチャ生成方式

[PLATEAU建物別イラストテクスチャ生成方式](開発関連/設計/PLATEAU建物テクスチャ生成/正式採用方式.md)を正本とします。写真に基づく部材別パターンと推測を区別し、公式PLATEAU形状に適用します。元127棟には個別写真なしの手続き生成44棟も含まれます。拡大建物も公式形状・UVを使い、対応する既存アトラスがない箇所は手続き生成です。写真照合済みとは扱いません。

ルート直下にはプロジェクト設定・README・ライセンス・アプリ入口のみを置きます。

| 配置 | 用途 |
|---|---|
| `src/`、`server/`、`shared/` | アプリ実装 |
| `public/` | 配信するモデル・テクスチャ・比較画面 |
| `scripts/`、`tests/` | 生成・運用処理と検証 |
| `scripts/launchers/` | 補助起動バッチ（旧版レビュー用を含む） |
| `開発関連/設計/` | 採用方式・基本設計・詳細設計 |
| `.tools/` | Git対象外のローカルランタイム・OCR資材 |
| `data/`、`test-results/` | Git対象外の作業データ・ログ・検証結果 |
| `_local-backups/tocho-adoption-20261029/` | Git対象外の旧実験・一時資料と復元情報 |

補助バッチは `scripts/launchers/` から実行できます。正式採用版の比較画面は、`public/` をHTTP配信して `/tocho-texture-comparison-20261019.html` を開きます。必要なローカル資産・検証方法は上記設計書を参照してください。補助バッチの旧版画面を正式採用版と混同しないでください。

都市そのものを、美術館へ進化させることである。
